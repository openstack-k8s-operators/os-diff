# OS-diff

**os-diff is retired and is no longer supported in Red Hat OpenStack Services on OpenShift (RHOSO) 18.**

This repository is kept only as a pointer. The GitHub project will be archived. Do not use the `os-diff` binary for RHOSP-to-RHOSO adoption or configuration comparison.

Use standard tools such as `diff(1)` and the procedures in the RHOSO 18 release notes and adoption documentation.
